# do you ever feel, like a plastic bag

A browser toy — float forever as a plastic bag through a wrapping world of Firework jokes.

## Run

```bash
npm install
npm run dev
```

## Controls

- **WASD / arrows** — move
- **Space** — rise
- **Shift** — drop
- **M** — mute
- **C** — cinematic camera

Music: looping bed (T1) + reactive stems (T2–T4).
